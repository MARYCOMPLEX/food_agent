# freeze-research-experience-contracts

Freeze the user-facing ResearchEvent v1 and UserResearchProjection v1 contracts for incremental evidence, controversy, profile, recommendation, and partial-failure updates.

Review order:

1. `analysis.md` explains the current Agent/runtime/observation boundary and
   the intended incremental flow.
2. `schema.md` is the field-level wire freeze with representative partial-run
   examples.
3. `specs/research-experience-contracts/spec.md` contains normative
   requirements and acceptance scenarios.
4. `tasks.md` records implementation and verification status.
