模块、技术栈与运行位置

Web UI / API 客户端

frontend/ · React 19 · Vite · Zustand

浏览器调用 REST，并通过 SSE 接收进度、断线重放和终态快照。

  • 运行：浏览器/静态前端开发服务器
  • 边界：只持有公开会话 ID，不持有平台 Cookie

FastAPI 应用

src/api/main.py · Uvicorn · SlowAPI · SSE-Starlette

统一搜索、历史、收藏、用户和健康接口；负责输入校验、CORS、限流和事件流。

  • 运行：app 容器，端口 8000（release 映射 18000）
  • 交互：调用 Composition Root/Use Case，不直接导入上游爬虫运行时

平台控制面 API

src/api/platform.py · /v1/platform/*

账号注册、登录/重认证、QR 状态、QR presentation、取消和 readiness 路由。

  • 运行：同一 FastAPI app；路由只接受 opaque credential_ref
  • 交互：app.state.platform_runtime_factory 注入 authority/codec/workflow；缺失时返回 503 disabled

Composition Root

src/xhs_food/composition/root.py
platform_bindings.py

唯一负责注册表、生命周期、feature flag 和依赖 readiness；新平台注册在独立 platform registry。

  • 默认：平台绑定完全关闭，legacy xhs_compat 不变
  • 回滚：关闭 flag，不改公共指针或历史证据

Canonical Contracts

src/xhs_food/contracts · Pydantic v2

CollectRequest、Query Family、Evidence 保持兼容；账号引用和会话版本位于独立 invocation envelope。

  • 禁止把 Cookie、QR、签名输入写入公开模型
  • 错误统一为 ContractError 分类

Domain / Agent 编排

orchestrator/ · agents/ · domain_packs/

ResearchCoordinator、StepScheduler、Food Pack、意图解析、评论分析和 POI 补充组成业务流水线。

  • 目标运行时：Pydantic AI V2（可替换端口）
  • 兼容：legacy facade 仍可按默认配置使用

Source Gateway + Capability Mux

gateways/platform_gateway.py
gateways/capabilities.py

先授权再取账号/会话，获取 PG lease 后构造一次性 connector；按 source/version 显式解决 capability 冲突。

  • 顺序：admission → grant → account → session → lease → provider
  • 退出：关闭 connector、清零内存 material、释放 lease

Temporal Durable Runtime

foundation/temporal.py · temporalio

唯一持久化执行引擎；Research、Refresh、Media 队列隔离，Account-auth 队列为可选资格化队列。

  • 每个队列有并发/优先级配额和 bounded retry/heartbeat
  • Workflow history 只含脱敏引用和状态

Activity Worker / Sidecar

Temporal Worker · optional provider sidecar

Activity 内只创建一个账号对应的 provider client；同步上游调用放入线程或隔离进程。

  • Spider_XHS Node signer 需 hash-pin、CPU/内存/时限约束
  • 不启动上游 API、SQLite scheduler 或 retry queue

登录应用服务

src/xhs_food/experience/platform_login.py

把 HTTP 命令转换为 account-scoped login use case；校验 principal、grant、幂等键和 opaque credential handle。

  • 注入 Temporal WorkflowPort 或本地 qualification coordinator
  • 只返回脱敏 flow/challenge/presentation metadata

Account Authority

foundation/platform_accounts.py
platform_account_repository.py

PostgreSQL/Alembic 管理账号、会话、登录流、grant、lease、health。自然键为 tenant × channel × account。

  • 渠道：dianping、xhs_pc、xhs_creator
  • 会话：AES-GCM envelope + key metadata + digest，CAS 版本

PostgreSQL / Alembic

SQLAlchemy 2 Async + asyncpg · PostgreSQL 16 + pgvector/pg_trgm

业务事实、Evidence、账号 authority 和 schema readiness 的唯一持久化来源；迁移只能由 Alembic 执行。

  • 运行：release compose 的 postgres 与一次性 migrate
  • 禁止：运行时 CREATE TABLE、上游 SQLite authority

Redis Hot State

foundation/redis.py · Redis 7

短期会话窗口、SSE stream、登录状态投影、限流和可重建热数据。

  • 运行：redis 服务；AOF 可用于重启恢复投影
  • 禁止：作为 lease/lock、长期账号事实或任务 checkpoint

ObjectStore

foundation/object_store.py · boto3 · S3/MinIO

二进制介质引用和短 TTL QR 对象；生产使用 S3，开发/CI 使用 MinIO。

  • 只向 API 暴露时限 presentation reference
  • 终态/过期后清理 QR，媒体由 Media queue 延后处理

Dianping Connector

gateways/platform_sources.py
composition/adapters/platforms.py

复用已审核快照的 auth/search/detail/reviews 协议模块，Playwright context 按 Activity 创建和销毁。

  • 源 ID：dianping；能力：place.lookup、reviews.search、media.refs
  • 排除：上游 FastAPI、SQLite、risk manager、CLI、worker

Spider_XHS PC Connector

XhsPcSourceConnector · pinned Spider_XHS

规范化 note search/detail/comments/media，分页受限，URL 去除 xsec_token 等 access query。

  • 渠道独立：xhs_pc 的签名器/会话不与 Creator 共享
  • 错误映射：406/429/risk/auth-expired/timeout → ContractError

Spider_XHS Creator Connector

XhsCreatorSourceConnector · pinned Spider_XHS

当前只注册账号自有内容读取和健康探针；发布、上传、排期和业务 API 明确未注册。

  • 源公共 ID 仍为 xhs，账号 channel 单独为 xhs_creator
  • 能力缺失时返回稳定 dependency/unregistered 错误

外部平台与 LLM

Dianping / Xiaohongshu · OpenAI-compatible endpoint

外部响应只在 adapter 边界出现；LLM 可配置 SiliconFlow/OpenAI/DeepSeek，旧高德 place capability 保持兼容。

  • 观测指标只使用低基数 platform/status/code
  • 凭据由 vault/KMS 或注入 codec 提供，不进入日志

一次账号绑定采集的交互顺序

1 · Request公开 CollectRequest + opaque account_ref/session_version
2 · AdmissionSourceControl 限流/熔断，不暴露账号存在性
3 · AuthorizePG grant → tenant/channel/account lookup
4 · Session读取 active version，codec 解密到 Activity 内存
5 · LeasePG durable lease，防止同账号 mutable client 并发
6 · Providerconnector 调用并规范化 canonical batch
7 · Finalizehealth/event → close → zeroize → release；SSE 只发脱敏状态

不可跨越的边界

当前 intake 仍是非生产资格状态。 两个上游快照都需要 owner/legal approval、审查后的依赖 digest 和（Spider_XHS）hash-pinned Node signer。没有这些证据时，代码允许 synthetic/unit qualification，但 Composition Root 必须报告 disabled/dependency-unavailable，不能用 fallback 掩盖配置缺失。
