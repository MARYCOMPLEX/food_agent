主要交互

    边界

    图中“权威”表示可写事实或唯一执行来源；虚线表示可重建、只读或待启用路径。模块只能通过项目拥有的 port / contract 交互。

    如何运行

    生产/验收路径使用 release manifest；默认 compose 仍保留为 legacy characterization，不应当作完整目标栈。

    docker compose -f docker-compose.release.yml up -d --wait docker compose -f docker-compose.release.yml exec -T migrate alembic upgrade head uv run --frozen uvicorn api.main:app --host 0.0.0.0 --port 8000

    一次请求怎么走

    • Browser 发送 HTTP/JSON；任务进度通过 SSE 订阅 Redis Stream。
    • FastAPI 只负责传输、身份、限流、DTO 和 use-case 调用。
    • ResearchCoordinator 形成 typed plan；Pydantic AI 只能调用 Tool Gateway。
    • Temporal Workflow/Activity 执行确定性边界；PG commit 后才发 terminal event。
    • 查询路径为 deterministic key → pg_trgm → BGE-M3 profile_v1 pgvector。

    当前发布边界

    当前分支的代码、文档、测试和远端已同步。唯一未闭合项是 B2 `10.12`：真实生产流量样本、召回/延迟/请求减少/错误分类观测，以及 release owner 对 canary 的批准。
    • PostgreSQL：业务事实、记忆、Bundle、task projection、outbox。
    • Temporal：唯一 executable checkpoint，Workflow ID 表达 single-flight。
    • Redis：session 热窗口、SSE stream、短幂等、限流；不是锁、队列或事实库。
    • S3/MinIO：只保存二进制；元数据和 provenance 在 PostgreSQL。
